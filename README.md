# 🩺 Medora

> **Your trusted companion for safer medicine & symptom discovery.**

Medora is a clean, clinical-grade search interface that helps people look up **symptoms**, **illnesses**, and **medicines** — and choose a safer next step. Built with care for clarity, accessibility, and trust by agents.

---

## 🌟 Overview

🔎 **What is Medora?**
Medora is a thoughtfully designed web app that delivers carefully sourced medical information at your fingertips. Whether you're feeling under the weather, researching a condition, or checking a medication, Medora guides you to reliable answers — fast.

💡 **Why Medora?**
- ⚡ Lightning-fast, distraction-free search experience
- 🛡️ Safety-first design with red-flag alerts and disclaimers
- 🎨 Beautiful, calming clinical UI
- 📱 Responsive and accessible on every device

---

## ✨ Features

### 🔍 **Smart Search**
- 🔬 **Symptom Search** — Look up what your body might be telling you
- 🦠 **Illness Search** — Get clear overviews of common conditions
- 💊 **Medicine Search** — Check dosage, warnings, and interactions
- 🤖 **AI-Powered Agent** — Medora's smart agent delivers structured, sourced answers

### 🚨 **Safety First**
- ⚠️ **Emergency Detection** — Instantly flags urgent terms like chest pain or difficulty breathing
- 🚩 **Red Flag Alerts** — Highlights when to seek professional help
- 📋 **Clear Disclaimers** — Always reminds you that Medora is informational, not a substitute for a doctor

### 💊 **Medicine Insights**
- 📝 **Dosage guidance**
- ⚠️ **Warnings & side effects**
- 🔗 **Drug interactions**
- 🎯 **Active ingredient info**

### 🩹 **Self-Care Guidance**
- ✅ Step-by-step self-care tips
- 🏥 When to seek professional help
- 📚 Review dates and sources for every result

### 🎨 **Premium UX**
- 🌊 Cobalt-and-aqua clinical theme
- 🖋️ Beautiful typography (DM Sans, Fraunces, IBM Plex Mono)
- 🌗 Clean, modern interface with smooth animations
- 📱 Fully responsive — works on phone, tablet, and desktop

## 🚀 Getting Started

### 📦 Prerequisites
- 🟢 Node.js 18+
- 📦 npm or yarn

### ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/medora.git

# Navigate into the project
cd medora

# Install dependencies
npm install

# Start the dev server
npm run dev
```

### 🏗️ Build for Production

```bash
npm run build
npm run preview
```
